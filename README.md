# Hospital Performance Dashboard

## Project Overview
An interactive four-page Hospital Performance Dashboard developed using Microsoft Power BI to analyze hospital operations, patient demographics, and financial performance.

## Dashboard Pages
1. **Overview** – Key hospital KPIs and summary metrics.
2. **Patient Analysis** – Patient demographics, medical conditions, and blood group distribution.
3. **Financial Analysis** – Hospital revenue and financial indicators.
4. **Hospital Performance** – Hospital-level performance metrics and comparisons.

## Tools Used
- Microsoft Power BI
- Power Query for data cleaning and transformation
- DAX for measures and KPIs
- Data visualization and dashboard design

## Key Features
- Interactive visuals and filters
- KPI cards and summary metrics
- Multi-page report navigation
- Data-driven hospital insights

## Files Included
- Power BI report (`.pbix`)
- Screenshots of all four dashboard pages

## How to View
Download the `.pbix` file and open it using Power BI Desktop.
